# Gyroship probe list, ready for the game's update that Gyroship targets: main's build ID
# a7730d0f74d168d90422354c8317f76ff78ad938. These are the trace: probes templates/practice.txt
# names. Compile them into the game, then build it again:
#   gyroship-tools recompile <exefs> --out generated/game --probes templates/probes.txt
# or name the file in the launcher's Practice probes field (Setup), then Recompile and Build. Another
# build has other addresses: docs/practice.md says how to find them.
#
# One "<address> <name>" per line: the address in hex (0x allowed here, unlike in the practice
# file), the name the rest of the line; # starts a comment anywhere. A probe runs before the
# instruction at its address, which must lie in a function the recompiler found: elsewhere it
# never runs, and nothing says so. The labels are free; a practice line names a probe by address.
# A name is trace:<label> [<item>...] [if <register>[&0x<mask>]=0x<value>[,0x<value>...]]: with
# the if part, only the passes where that register, masked, holds one of the values go to the
# --trace file.
