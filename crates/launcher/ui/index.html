Setup

Do these steps once, in order, then go back to Play. Each step's light turns green when it is done.

Setup is not finished. Until it is, Play has no game to start.

    1. 1. Folders

      Tell the launcher where things are. The repository is the folder of Gyroship's sources, where the game gets built. The data folder is any folder you choose: it keeps the builds you set aside (bin), the mods (practice), the launcher's save copies and the logs of your sessions.

    2. 2. Rust and Microsoft's C++ tools

      Building the game needs Rust and Microsoft's C++ build tools; playing it needs the Visual C++ runtime. Install gets what is missing through winget, Windows' own installer: it downloads from the Rust project or Microsoft, and may ask for administrator rights. Nothing is installed unless you click, and clicking accepts the package's licence (the Rust project's, or Microsoft's).

      • Rust
      • C++ build tools
      • Visual C++ runtime
      • Gyroship's tools

      winget is missing: get "App Installer" from the Microsoft Store, or install Rust and the C++ build tools yourself.

    3. 3. Recompile the game

      Turns your copy of the game, from the exefs folder set in Play, into code for this PC. About two minutes. Do it again after changing the practice probes, or after updating a Git clone of Gyroship (build the tools again first). After an update through the launcher, it runs by itself.

    4. 4. Build the game

      Puts the recompiled code and Gyroship's engine together into gyroship.exe, the game you play. A few minutes the first time, when it also downloads what it is built from; then seconds.

    One step at a time, never during a game. Their messages show below.

    

      
    
        
    Updates
    
        
    When a new version of Gyroship is out, the launcher downloads it from GitHub and installs it next to this copy, which stays until you delete it. It then builds the game again for it, as in steps 3 and 4. A Git clone is only told: update it with git pull, then build the tools and the game again. The game itself never goes online.
